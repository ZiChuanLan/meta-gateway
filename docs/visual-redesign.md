# Meta Gateway 视觉与工作区重设计

日期：2026-09-14。目标是统一整个控制台的结构和视觉语言，包括登录入口、导航、列表、配置面板、浮层及切换过程。

当前交付采用两套完整界面包：设置 → 外观可以选择经典控制台或现代工作空间，布局与过场随包切换，明暗仍独立设置。包结构、原版来源与扩展边界见 [ui-themes.md](ui-themes.md)。下述工作区整理主要描述现代包。

## 原界面的主要问题

1. 顶部导航、统计卡片、筛选、详情与操作的视觉重量接近，视线缺少明确的落点。
2. 宽表格与详情并排，实际数据被挤窄；模型配置的主要操作被历史、统计和说明推到首屏之外。
3. 大量边框、全大写标签、等宽字体与持续装饰，让页面显得忙碌，内容之间的关系不够清楚。
4. 颜色、圆角和动画定义散落在多轮 CSS 覆盖中，组件之间缺少稳定的规则。

## 新的视觉规则

- **纸白与石墨底层，蓝色主操作**：现代包采用中性表面、清楚的黑白对比与蓝色强调，少量珊瑚红区分辅助图形；经典包保持原版蓝金配色。
- **导航、内容、浮层三层结构**：侧栏与顶栏帮助定位，内容获得主要对比度，菜单和编辑器通过适量阴影表达覆盖关系。
- **字体有明确用途**：Inter 与中文系统字体负责正文、标题、数据；JetBrains Mono 只用于模型标识、路径和技术内容。移除两套未继续采用的字体请求。
- **空间按关系分配**：页头操作固定；统计降为轻量读数；表格减少重复边线；表单使用一致的字段间距和操作页脚。
- **动效有长短层次**：按钮反馈约 120–180ms、菜单约 160ms、页面进入约 260ms并带 420ms 的斜向光扫；主题切换使用 520ms 的斜切揭幕。登录成功后的品牌入场为 920ms 建立与停顿 + 1180ms 揭幕，总计约 2.1 秒，可随时跳过。

## 动效行为与性能

- 入场：经过验证的登录会话才开始过场；认证、过场和总览的「重播入场」各自管理状态。重播不重新登录、不发请求、不改变会话。
- 退出：650ms 收场，遮罩合拢后断开连接。跳过按钮与 Escape 可以结束入场、重播或退出；结束后清理计时器、滚动锁和焦点。
- 引导：首次使用的功能导航在入场完成后显示，避免两个覆盖层同时争夺焦点。
- 减少动态效果：遵守系统 `prefers-reduced-motion`，停止粒子、光轨和大幅运动，登录/重播走约 160ms 的短路径，关闭主题揭幕。手机保留完整标题与 44px 高的跳过入口。
- 粒子：约 30fps，桌面最多 88 / 手机最多 36，DPR 不超过 1.5，画布最多约 300 万像素；隐藏页面停止 RAF，卸载时释放观察器与事件监听。按钮火花有兜底清理。
- 首页：SVG 光轨属于品牌装饰，隐藏于无障碍树，不表达实时请求流量；滚出视口或页面隐藏时暂停。统计与图表仍展示真实接口数据。

## 维护入口

- `web/src/themes/registry.ts`：完整主题包注册；每个包拥有导航、详情展示、入场组件和样式。
- `web/src/styles/tokens.css`：现代包浅深模式的文字、颜色、间距、阴影与动效变量。
- `web/src/styles/system.css`：共享控件、表格、表单、菜单、抽屉与对话框。
- `web/src/styles/shell.css`：导航、页头、响应式框架和页面进入动效。
- `web/src/styles/workspaces.css`：各工作区的信息组织和布局。
- `web/src/styles/login.css`：登录布局、表单与材质。
- `web/src/styles/motion.css`：登录粒子配套样式、品牌入场、首页光轨、导航/标签/菜单反馈与主题揭幕；动效降级也集中在此。
- `web/src/lib/entranceMotion.ts`：入场/退出时长；CSS 与认证/重播计时器共享这些值。
- `web/src/styles.css`：保留业务专用布局；移除 307 条旧共享/壳层规则和 233 条旧登录/过场规则，避免继续叠加同一职责的定义。

`PageActions` 允许业务组件将当前操作放进页头，同时保留其本地状态和事件处理。新的壳层由 `ConsoleShell` 统一维护。图片协议、透传、路由选择、计费与视频 API 的既定范围不变。
