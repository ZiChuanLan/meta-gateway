# 运维

这一节覆盖**部署之后**的事：配置、数据、备份、告警、观测与排查。

## 运行形态

一个进程 + 一个 SQLite 数据库。数据库与备份都在 `DATA_DIR`（容器内 `/data`）。没有外部依赖、没有独立缓存、没有需要另外维护的消息队列。

## 配置分三层

| 层 | 位置 | 何时生效 |
| --- | --- | --- |
| **环境变量** | 部署文件（`.env` / compose） | 需要重启 |
| **运行设置** | 控制台「运维 → 运行设置」，存 `runtime_settings` 表 | 大多热生效，无需重启 |
| **路由 / 渠道级** | 各自的行上（超时、并发、重试、代理等） | 保存即生效 |

环境变量是**启动时的初始值**，运行设置是对它的覆盖。想彻底关掉某个后台任务，两处都要看。

## 三条不能违反的约定

1. **`MASTER_KEY` 必须随库一起备份、一起迁移。** 换一个 `MASTER_KEY` 打开同一个库，所有加密字段都解不开。
2. **已应用的迁移文件不能改名、不能编辑。** `schema_migrations` 按**文件名**记录，改名字等于让迁移重放。
3. **`internal/webui/dist` 是构建产物但被跟踪**，因为 Go 二进制 `go:embed` 它。重新构建后要单独提交，不要混进源码提交。
