# 定价配置

## 编辑网关收费

- **模型默认规则**：模型页选中模型 →「计费规则」。
- **成员覆盖**：模型详情 → 成员的更多操作 →「计费规则」；只影响这个路由成员。
- **上游报价**：在成员计费面板下半部查看，或连接 → 站点观测 → 某模型 → 打开对应成员的计费面板。
- **模型倍率**：计价面板的倍率管理保留，倍率作用于该模型全部下游账单，不改变规则优先级。

能力元数据与成员路由编辑器不再编辑价格。已有旧价保留为「兼容旧规则」；打开查看不会改价。

## 规则状态与计量方式

先选择「继承下一层」「明确免费」或「自定义计费」。自定义支持按量、按次和按量＋每次附加费，不能用切换模式意外叠加两种收费。

按量字段为 USD / 1M tokens：普通输入、输出、缓存读取、缓存写入。**0 表示免费，空白表示未知**；普通输入和输出必须明确填写，或提供完整阶梯。缺少缓存费率不会自动回退收费。

按次字段为 USD / 调用。只按次时不保留 token 费率；成功响应即使没有 token usage 也能记固定费。

高级区配置阶梯、时段倍率及 IANA 时区。清空已有档位字段会阻止保存，全空的新档位不计入规则；新规则在承接成员确定时冻结，修改只影响未来请求。

## 保存与冲突

保存携带打开时的版本。别人先修改同一规则时返回冲突，原输入保留；选择「重新载入规则」后才能基于新版本修改。关闭或离开有未保存修改的面板会询问，选择留下保留输入。

规则保存成功后显示版本与当前承接层。全局显示币种只影响读数，不改变输入的 USD 金额或历史账单。

## 复制报价

参考目录、公开站点、登录账户分组和手工上游报价各自独立。点击「比较并复制」：

1. 查看旧网关规则、所选报价、采集时间和适用分组。
2. 若报价不是明确 USD，声明每一原生计价单位对应多少 USD。此比例与站点显示汇率、网关外观汇率不同。
3. 一次确认生成新的网关规则。

提交锁定报价 ID 与目标版本。看过的报价被刷新、目标规则改变、模型/站点/账户/分组不匹配时不能悄悄换值提交。复制不是自动跟价，未来刷新报价不会改账。

手工上游报价通过「记录上游报价」保存，要求原生单位、适用分组和明确费率；它只新增报价观察值。要用于收费仍需单独复制。

## 按场景测算

在报价下展开「按场景测算」，输入普通输入、输出、缓存读写与同单位可用余额。计算由后端统一执行，结果对应这次场景；更改输入后需重新测算。

过期报价、不支持的表达式、未知单位或缺少实际使用维度的价格会给出原因，不显示成免费。可承担次数只是理论预算，不取代 Key 配额、共享消费、授权、速率和到期限制。

## 核对账单

发一次请求，在日志详情展开「请求结算依据」核对规则版本、计量来源、费用和倍率。旧账没有规则快照会明确说明，不补造来源。免费、未定价、缺价、无用量和估算分别显示。
