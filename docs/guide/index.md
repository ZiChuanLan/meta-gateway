# 入门

Meta Gateway 是自托管的 AI 网关 + 管理控制台：对下游暴露 OpenAI / Anthropic 兼容协议，对上游聚合多个站点的账号与模型，做路由、故障转移、用量计费与审计。

架构上坚持**透明 pass-through**——不改写请求语义、不注入提示词、不伪造响应。

## 核心概念里最容易混淆的两件事

1. **「分组」有两个完全不同的含义**：路由成员分组（决定一组渠道怎么承接某个模型）与令牌分组（决定一批下游令牌共用多少额度与限速）。详见[核心概念](./concepts#两个分组不是一回事)。
2. **「路由」不是渠道**：渠道是「哪个上游账号能用」，路由是「模型名怎么被承接」。一个路由挂多个渠道成员，成员还可以分属不同分组。
