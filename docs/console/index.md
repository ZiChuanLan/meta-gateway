# 控制台

管理控制台嵌在 Go 二进制里，由网关自己提供，访问路径 `/console/`。

## 信息架构

| 区域 | 主要页面 |
| --- | --- |
| **总览** | 仪表盘、实时吞吐、渠道健康、流量追踪 |
| **上游** | 站点与连接、渠道（含凭据与模型）、模型发现 |
| **模型** | 模型目录、路由与成员、能力注册表、模型变更、站点探针 |
| **令牌** | 下游令牌、令牌分组与配额 |
| **团队** | 模式、成员与邀请、策略、公共渠道授权、第三方登录 |
| **日志** | 代理日志、审计事件、实时追踪 |
| **工作台** | 图像跑测、文字跑测 |
| **拓展** | 插件市场、已安装插件、sidecar 注册 |
| **运维** | 运行设置、告警规则、错误规则、提示词护栏、备份、维护、TOTP |
| **外观** | 主题包、明暗与配色、界面入口自定义 |

## 静态资源与缓存

- 无扩展名的嵌套路径（如 `/console/routing`）返回 SPA 外壳。
- **缺失的资源路径返回 `404`，绝不回退成 HTML** —— 否则客户端会拿到一份 HTML 去当 JSON 解析。
- HTML 用 `Cache-Control: no-cache`；带内容哈希的资源用一年期不可变缓存。

## 两套界面包

设置 → 外观可以在**经典控制台**与**现代工作空间**之间切换，布局与过场随包整体变化。

**主题包、明暗、配色是三个彼此独立的维度**：调整其中一个不会重置另外两个。偏好存在浏览器本地，不影响同实例的其他使用者。

## 界面入口可配置

两类入口都能隐藏或显示，存在浏览器本地：

- **顶栏控件**：搜索、更新、主题、语言；
- **导航项**：按路径记录（如隐藏「签到」）。

隐藏不等于删除：路由照旧挂载，命令面板始终列出全部页面，面板里还有「恢复默认」。退出登录不参与开关——它是控制台唯一的登出入口。

> 一个页面只有一个入口。签到的顶栏快捷按钮已经删掉了，因为它和导航里的「签到」指向同一页，两个副本各自需要一个开关才不含糊。

## 交互约定

- 每个区域突出**一个主要操作**，行内只留高频项，其余收进「更多操作」；右键菜单与「更多操作」共用同一份动作定义，禁用项带原因说明。
- 抽屉与确认框统一 pending 锁定、关闭限制与焦点恢复；列表行支持 <kbd>Shift</kbd> + <kbd>F10</kbd> 唤起菜单。
- 弹层遵守统一的位置、键盘与焦点约定，并同时验收桌面与手机。

## 列表页状态持久化

模型、连接、令牌、日志这些列表页的**搜索词、选中项、筛选条件、分组方式**在页面之间切换后保留。存在 `sessionStorage`（**标签页级**），不是 localStorage——筛选项是一次会话内的临时意图，写进 localStorage 会让昨天的筛选在今天依然生效。

详见[列表页状态](./list-state)。
