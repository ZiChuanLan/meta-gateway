# 实施交付记录（价格分层 + 全站体验）

基线：`experiment/availability`，起点 `28913cfb4c04f2eb33d776bcb4452b9f3fbc8b19`。
依据：已批准的 `2026-10-12-availability-lab.md`（`meta-gateway/.pi/plans/`）与两份审查报告。
本记录只报告**已实际验证**的结果；未运行的环境门禁单独列出。

## 2. 报价、原生额度与网关计费分离（计划第 2 节）

- 新增 `price_quotes`（不可变快照：来源、用途、原生单位、账户/分组作用域、观察时间、过期、状态、原始载荷）与版本化 `billing_rules`（继承/明确免费/自定义/兼容旧规则）。迁移 `132_pricing_boundaries.sql`、`133_finance_snapshots.sql`。
- 参考目录、上游观察、人工报价**只写快照**；`model_metadata`/`route_members` 旧价列保留为 `legacy` 读取，不清空、不重算历史、不猜来源。
- 计费只读本地规则；请求选中承接成员时冻结版本、倍率与计价时间，处理中改价不追溯。未定价尝试也会冻结 `unpriced`，避免“事后新增价格把旧请求变成收费”。
- 明确免费压过旧价（`free` 整层生效）；层内不逐字段回退；新规则的缓存价 `0=免费`、空白=`未知`，缺价时标记缺价而不按输入价收费。
- 报价复制携带 `quote_id` + `expected_revision`，事务内校验目标（模型/成员/站点）与规则版本，并记录来源证据。
- **语义修正（本轮新增）**：原先“必须是最新一条报价”的门禁会让后台每两分钟一次的账户刷新把已核对报价变成冲突。现改为**过期才拒绝**（`Status=calculable` 且未过期即可复制），复制的始终是用户看过的那个快照，`quote_id` 留证。回归：`TestQuoteCopyFreeCacheAndVersion`（刷新后仍可复制、过期拒绝）、HTTP `TestBillingRulesHTTPSeparateQuotesAndPolicy`（重新复制回到所看报价）。

## 3. 余额、估算与金额解释（计划第 3 节）

- 财务读取改为本地快照 + 单飞刷新：按账户/分组去重，失败保留**同账户**最后一次成功值并标记过期，不显示 0，不在浏览时同步等待上游；快照按渠道保留上限并持久化（重启可读）。
- 修正连接详情把 `quota` 再减 `used_quota` 的展示（该字段已是剩余额）。
- 删除成员行“≈10M”推算；估算改为后端按场景（普通输入/输出/缓存读写 + 同单位余额）计算，返回 `cost_per_call`/`calls` 或具体不可用原因（缺价、单位不符、过期）。零价明确返回“零价不代表无限调用”。
- 日志详情新增「请求结算依据」：规则归属、版本、来源、用量来源（上游/估算/缺失）、费率（USD/1M 展示）、模型倍率、时段倍率、时区、缓存量。成员接口不返回该注解。

## 4. 全站交互与外壳（计划第 4 节）

- **未保存编辑保护**：迁到官方 data router + `useBlocker`，覆盖侧栏、命令面板、程序化 `navigate`、浏览器前进/后退与 `beforeunload`；补品牌设置与成员偏好的草稿保护（后台刷新不覆盖脏输入，保存失败保留草稿）。
- 错误归因：管理面 429 不再表述为“上游限流”，区分 `gateway_admin` 与上游；成员空态提供其权限内的下一步（新建令牌／打开工作台）。
- 文案修正：令牌“仅显示一次”不再与加密存储、可重新查看矛盾；模型同步/接入说明与实际模式一致。
- 普通管理员复用共享 `ConsoleShell`（只显示授权导航，不扩大权限）；命令面板按角色过滤。
- 交换页改为「导入／导出／云同步」三个任务（`?task=` 深链接），切换保留文件、选择与 WebDAV 草稿；保存期间的新输入不会被旧响应覆盖。

## 5. 界面、排版与动效（计划第 5、6 节）

- 手机模型目录：<=760px 改为“目录 + 详情弹层”，实测 `.list-shell-body` 从 123px 变为 `max-height:none`，可返回目录。
- 共享字号下限上调（`--text-xs` 11→12px 等，两套主题同步），表格/表单/分页统一；手机表单 16px 字号与 44px 触摸目标。
- 设置：手机提供分区选择器（桌面索引栏保留）。
- 动效：日常登录**立即建立会话**、180ms 淡入，不再等待 2.1s 品牌演出；完整演出保留在总览「重播入场」。移除切页斜向光扫、主题 520ms 斜切（改 180ms 淡入）、常驻呼吸动画；统计数字直接显示真实值（删除 count-up），隐藏页暂停装饰动画。
- 包体：按框架/词典拆分（入口 JS 935kB→207kB，框架 288kB、词典 413kB 独立可缓存）；同时如实说明冷启动总下载量并非同比例下降。

## 7. 与计划的偏差

1. **报价“最新版本”门禁改为过期门禁**（见 §2）。计划要求“提交时检查报价和规则版本”，本实现保留规则版本检查与目标校验，把“是否有更新观测”从拒绝条件降级为过期条件——否则正常账户刷新会让复制必然失败。审查报告中被列为“风险”的并发替换问题因此按“所见即所复制 + 证据留痕”解决。
2. **首个 30 分钟超时的导航任务**：子代理超时后由父代理复核其两次提交（`66d43c7` 早期实现 + `1365325` 官方 data router 方案），最终合入的是 data router 版本。
3. **模型倍率入口**：计划未单列，实际把它并入计费面板（`ModelRatioDialog`），旧用户管理入口保留兼容。
4. **文档**：`docs/billing/index.md` 重写，`docs/console/visual-design.md` / `themes.md` 更新为新的动效与首登行为；`docs/reference/*` 未手改（生成物由 docsgen 维护，本次未改动其输入事实以外的内容 → 需在合并前跑一次 `go run ./tools/docsgen` 核对）。
